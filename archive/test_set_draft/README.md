# Test set · 50 cases

All clients, CAs and conversations are fictional. Source of truth: `cases/*.yaml`; `cases.json` is generated by `scripts/build_test_set.py`; chat screenshots in `screenshots/` are rendered from the same history by `scripts/render_chats.js`.

Each case's conversation history exists in two forms: **structured text** (ground truth) and a **WeChat-style screenshot** (tool input, as a CA would forward it). Comparing the tool's reading of the screenshot against the text lets us measure screenshot parsing separately from message quality.
