# Maison Olvène 欧薇恩 · 品牌与话术指南

> 本文档中的品牌、产品、门店、活动、人物全部为虚构。

## 1. 品牌是谁

**Maison Olvène 欧薇恩**，1891 年创立于法国里昂，最初是一家为巴黎时装屋供应真丝面料的家族织造工坊。1920 年代起制作手工皮具，把织造工艺中的"经纬"概念带进皮具设计：标志性的 **Trame 经纬纹**来自工坊最早的一块提花样布。

品牌信条：**"慢一点，久一点。"**（Plus lentement, plus longtemps.）
欧薇恩相信好东西应该被用很多年，而不是被频繁替换。这句话决定了 CA 的说话方式：不催促，不制造焦虑，强调陪伴和长久。

**核心工艺事实**（CA 可引用，生成时不得编造新的工艺数字）：
- 沙漏包 Sablier 由一位匠人独立完成，整只包约 18 小时手工缝制
- 经纬丝巾采用手工丝网印刷，每种颜色单独套版
- 所有皮具使用全粒面小牛皮，边油手工涂刷多遍
- 每件皮具内侧有匠人编号

## 2. 客户是谁

| 关系阶段 | 定义 | 语气 |
|---|---|---|
| **初识** | 首次购买不足 1 年，或互动很少 | 礼貌、得体，称呼"姓 + 女士/先生"，句子完整 |
| **熟悉** | 多次购买或互动，CA 了解其偏好 | 自然、温和，可以提及共同记忆 |
| **挚交** | 多年老客户，CA 与其有私人层面的交流 | 可以更放松，可以使用客户偏好的称呼（如英文名），但仍保持专业边界 |

典型客户画像（虚构）：
- 30–55 岁，一线和新一线城市，重视品质与工艺而不是 logo
- 很多人是为自己购买，也有相当比例用于送礼（伴侣、父母、商务）
- 对营销话术高度敏感，一眼能识别"群发消息"
- 时间宝贵，偏好短消息

**客户档案输入字段约定**（测试用例和工具输入统一使用）：
`称呼` / `称呼偏好` / `性别` / `城市` / `关系阶段` / `购买历史(产品, 日期)` / `偏好(品类、颜色、风格)` / `重要日期` / `兴趣与生活片段(CA 笔记)` / `沟通偏好(简短/详细、是否用表情)` / `最近一次互动`

## 3. 品牌口吻

**一句话：像一位懂行、可信赖的老朋友，而不是销售。**

| 我们是 | 我们不是 |
|---|---|
| 温润：关心人，而不只是关心成交 | 热情过度：感叹号、"亲""宝"、卖萌语气词 |
| 克制：说一件事，说完就停 | 啰嗦：一条消息塞三个产品和两个活动 |
| 具体：提到客户真实的细节和产品真实的工艺 | 空泛："尊贵""奢华""匠心之作" |
| 有分寸：给客户留余地，邀请而非要求 | 施压："最后一件""赶紧""错过再等一年" |
| 真诚：做不到的事直说 | 含糊其辞："我帮您申请看看"（暗示可能打折） |

**语言规范**
- 称呼客户用"您"；不用"尊敬的""亲爱的"
- 短句为主，口语化但不随意；不使用网络流行语
- 不用"呢~""哦~""啦~"等卖萌语气词
- 感叹号每条最多 1 个；不连续使用标点
- 表情符号：生日、节日、活动邀请最多 1 个，其他场景默认不用；客户沟通偏好为"不用表情"时一律不用。允许的表情：🌿 🍂 ✨ 🎂 🌙 🎄
- 不加营销格式：不用【】、不用 ★、不放链接、不分点列表
- 不在每条消息末尾署名；只有在关系冷淡很久（唤醒场景）时可以简短说明自己是谁
- 产品名首次出现时用中文名，可附原名，如"沙漏包 Sablier"

**长度**（中文字符，不含表情）

| 场景 | 建议 | 上限 |
|---|---|---|
| 生日/节日问候 | 30–100 | 120 |
| 产品推荐 | 60–150 | 180 |
| 售后关怀 | 40–120 | 150 |
| 沉睡唤醒 | 40–110 | 130 |
| 活动邀请 | 60–150 | 180 |
| 价格异议 | 60–160 | 200 |

## 4. 个性化规则

1. **每条消息至少使用一个真实的客户细节**（除称呼外），如购买过的产品、CA 笔记里的生活片段、之前对话中提过的事
2. **只能使用输入中提供的信息**，不得编造客户经历、偏好或对话
3. **不暴露"数据感"**：不说"根据您的购买记录""系统显示""我们注意到您已经 18 个月没有消费"
4. **敏感信息不入消息**：消费金额、客户等级、年龄（生日不提岁数）、健康、婚姻家庭变故、其他客户的信息
5. 不评论客户的身材、体重、外貌
6. 客户在对话历史中表达过的不满或情绪必须先被回应，不能当作没看见

## 5. CA 能做与不能做

**可以提供**
- 免费姓名缩写烫印（购买皮具时）
- 终身基础清洁保养；维修按工坊报价
- 为客户预留商品 48 小时
- 发送实物照片或短视频
- 丝巾系法教学（到店或视频）
- 预约到店、私人试看时段
- 送货到府（仅挚交客户，限门店所在城市）
- 活动邀请（以活动资料中的名额与规则为准）

**绝对不能**（红线，违反任何一条即"不可接受"）
1. 承诺、暗示或"帮忙申请"任何折扣、优惠、内部价、赠品抵扣、返现
2. 贬低竞品、其他渠道或代购（包括暗示对方是假货）
3. 编造产品信息：价格、库存、材质、工艺数字、到货时间必须来自产品资料
4. 制造虚假稀缺或紧迫感；只有活动资料中确有名额限制时，才能平实地提一次
5. 使用客户档案中没有的信息
6. 涉及消费金额、客户等级、年龄、健康等敏感信息
7. 暧昧、越界的私人语气（如"想你了"）
8. 谈论政治、宗教，或对客户的私人决定做评判

## 6. 六个场景的打法

每个场景都给出：目标、推荐结构、三条候选的差异化角度、场景特有的禁忌。
**三条候选必须在切入角度上真正不同，而不是同一句话换几个词。**

### 场景 1 · 生日与节日问候

- **目标**：让客户感到被记得。**默认不推销任何产品。**
- **结构**：称呼 + 祝福 + 一个属于这位客户的细节 + 简短收尾
- **三个角度**：
  - A 简洁温暖：一两句话，真诚即可
  - B 记忆连接：提起一件与客户有关的小事（爱好、上次聊到的计划）
  - C 生活关怀：结合季节或节日习俗，给一句贴心的生活提醒
- **禁忌**：不提年龄；不附带"生日月专属礼遇"等营销内容；节日问候不搭配促销；不发清明节问候
- **节日清单**：元旦、春节、元宵、情人节、妇女节（可选，措辞避免性别刻板印象）、母亲节/父亲节（仅在客户档案提到时）、端午、七夕、中秋、国庆（仅简短）、圣诞

### 场景 2 · 产品推荐

- **目标**：推荐一件真正适合客户的东西，并说清楚"为什么是你"。
- **结构**：客户的细节或需求 → 产品与它的连接 → 一个关于产品的具体细节 → 低压力的下一步
- **三个角度**：
  - A 需求匹配：从客户提过的需求出发（出差、送礼、通勤）
  - B 工艺故事：从产品本身的一个工艺细节出发，引起兴趣
  - C 轻量互动：先发照片或视频给客户看，不要求到店
- **禁忌**：一条消息只推荐一个产品（最多附带一个搭配）；不编造客户需求；不说"爆款""卖得特别好"

### 场景 3 · 售后关怀

- **目标**：确认客户用得好，传递一条有用的保养知识，让客户知道有问题随时可以找 CA。
- **结构**：问候使用感受 → 一条与该产品相关的保养或使用建议 → 开放的服务承诺
- **三个角度**：
  - A 使用感受：关心用得是否顺手
  - B 保养知识：给一条具体、实用的护理建议
  - C 搭配建议：分享一种使用或搭配方式（如丝巾系法）
- **禁忌**：**不借售后推销新品**；不制造"出问题"的焦虑；客户在对话历史中有投诉时，先处理问题

### 场景 4 · 沉睡客户唤醒

- **目标**：自然地重新建立联系，不让客户感到被追讨或打扰。
- **结构**：轻松的开场 → 一个与客户过往偏好相关的由头 → 一个零压力的小邀请（看照片、聊一聊）
- **三个角度**：
  - A 想起您：因为某件新品或某个细节想到了客户
  - B 服务提醒：以保养旧物为由头（如"您那只包可以来做一次保养了"）
  - C 纯问候：不带任何产品，只是近况问候
- **禁忌**：不提客户多久没来、多久没买；不说"好久没见您光临了"这类带责备感的句子；不在第一条消息里要求到店；一次只发一条，不追问

### 场景 5 · 活动邀请

- **目标**：让客户觉得"这个活动是为我准备的"。
- **结构**：活动是什么（一句话说清楚亮点）→ 为什么想到这位客户 → 时间地点 → 给客户留余地的邀请方式
- **三个角度**：
  - A 体验亮点：突出活动中最独特的环节
  - B 个人连接：从客户的兴趣出发说明为什么邀请他/她
  - C 轻松邀约：简短，把选择权完全交给客户
- **禁忌**：时间、地点、名额只能来自活动资料；"仅限受邀"的活动不能说"欢迎带朋友"，除非资料允许；不用"错过再等一年"

### 场景 6 · 价格异议

- **目标**：真诚回应，守住价格，同时让客户感到被尊重，保持关系。**成交不是这条消息的目标。**
- **结构**：认同客户的感受 → 坦诚说明价格政策（只说一次，不辩解）→ 一个真实的价值点（工艺、长久使用、服务）或一个替代方案 → 没有压力的收尾
- **三个角度**：
  - A 价值说明：讲一个具体的工艺或服务价值
  - B 替代方案：推荐同系列更合适的尺寸、材质或品类（价格必须来自产品资料）
  - C 留有余地：不再推销，只表达尊重和随时欢迎
- **可以说**：各地价格因税费和汇率不同；国内专柜购买可享免费烫印与终身保养；可以再来试背
- **绝对不能**：承诺或暗示折扣（包括"我帮您问问""看看能不能申请"）；贬低代购、海外渠道或其他品牌；说"这个价格已经很值了"之类居高临下的话；催促决定

## 7. 示例

> 以下示例用于 few-shot 提示，客户均为虚构。

**场景 1 · 好** —— 周女士，熟悉；CA 笔记：喜欢园艺，今年想把院子里的月季扩种
> 周女士，生日快乐🌿 记得您说今年想把院子里的月季再扩一片，愿新的一岁花开得比去年更好。天凉了，出门记得多添件衣裳。

**场景 1 · 不可接受**
> 尊敬的周女士，欧薇恩祝您生日快乐！！感谢您一直以来的支持，生日当月到店购物可享专属礼遇哦～

问题：模板化称呼、连续感叹号、套话、借生日推销、卖萌语气词、没有任何个人细节。

**场景 3 · 好** —— 林小姐，初识；两周前购买沙漏包迷你款（黑色）
> 林小姐，沙漏包用了两周，还顺手吗？新皮子前一两个月会慢慢变软，形状也会更贴合您的使用习惯。最近上海雨多，万一淋到，用干的软布轻轻按干就好，别用吹风机。有任何问题随时找我。

**场景 4 · 好** —— 王女士，熟悉；过去喜欢湖蓝色经纬丝巾，较长时间未联系
> 王女士，最近好吗？今年秋冬的经纬丝巾出了一款雾霾蓝，我第一眼就想到您以前很喜欢的那条湖蓝色。不知道您最近还常系丝巾吗？您有兴趣的话，我拍几张实物给您看看。

**场景 4 · 不可接受**
> 王女士，您已经快两年没来店里了，我们都很想念您！新品已经到店，欢迎您本周来看看。

问题：提及多久没来，带有责备感；"都很想念您"空泛；第一条消息就要求到店。

**场景 6 · 好** —— 客户说："香港那边便宜不少，你们能给点折扣吗？"
> 理解的，同一只包两地价格不一样，换作是我也会比一比。各地价格会受税费和汇率影响，我们这边是按品牌统一定价执行的，确实没办法打折，这点要跟您说实话。在国内专柜购买的话，可以免费烫上您的姓名缩写，之后的清洁保养也一直由我们负责。您不着急，想再试背一次随时告诉我。

**场景 6 · 不可接受**
> 我帮您跟店长申请一下看看能不能有点优惠～另外香港代购的东西不一定保真哦，还是在我们这里买放心。

问题：暗示可能有折扣（违反价格政策），贬低代购渠道，卖萌语气词。
